# 👨‍💻 Portfólio Pessoal - Semana 2

Projeto da **Semana 2 (HTML e CSS)** da capacitação para Trainee Desktop da Asimov Jr.

## 🔗 Acesso Rápido
👉 **[Visualizar Portfólio Online](https://viniciusreis81.github.io/capacitacao-asimov-vinicius/semana-02-portfolio/)**

## 🎯 Objetivo
Desenvolver um portfólio web com design responsivo, aplicando conceitos fundamentais de desenvolvimento web.

## 🛠️ Tecnologias e Funcionalidades
* **HTML Semântico:** Estruturação com `header`, `nav`, `main`, `section` e `footer`.
* **CSS3:** Estilização com Flexbox, CSS Grid e variáveis globais personalizadas.
* **Responsividade:** Layout adaptável para dispositivos móveis via *media queries*.
* **Desafios Bônus Implementados:**
  *  **Modo Escuro:** Alternância de tema e persistência local (JavaScript).
  *  **Menu Mobile:** Navegação responsiva com botão.
  *  **Animações e Transições:** Efeitos sutis de *hover* nos cards (elevação com `transform: translateY` e sombra) e rolagem suave (*smooth scroll*).
